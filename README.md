# ALT:PARKING Guard для Android

Здесь публикуются официальные установочные файлы приложения охранника
ALT:PARKING. Исходный код приложения находится в закрытом репозитории.

## Скачать

Откройте [последний релиз](../../releases/latest) и скачайте файл
`ALT-PARKING-Guard-vX.Y.Z.apk`.

Минимальная версия системы — Android 7.0 (API 24). При установке из браузера
или файлового менеджера Android может запросить временное разрешение на
установку приложений из этого источника.

## Проверить файл

Сравните SHA-256 скачанного APK со значением из `SHA256SUMS.txt`:

```powershell
Get-FileHash -Algorithm SHA256 .\ALT-PARKING-Guard-vX.Y.Z.apk
```

```bash
sha256sum ALT-PARKING-Guard-vX.Y.Z.apk
```

## Поддержка и права

Для обращения в поддержку используйте действие «Поддержка» внутри приложения.
Опубликованные бинарные файлы являются проприетарными. Публичность этого
репозитория не предоставляет лицензию на исходный код или модификацию
приложения.
